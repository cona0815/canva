## 1. 課程需求（為什麼要做這個工具）

### 1.1 這是哪一堂課

五年級資訊課的 Canva 單元。上一個單元是「我的主題大探索」：學生自選主題、上網找圖、上傳 Canva 做簡報，網站在同一個 repo 的 `topic-explore/`。下一個單元是 **Canva 虛擬主播**：學生做一支卡通主播影片，主題自由選，可以延續「我的主題大探索」的主題。

### 1.2 虛擬主播在 Canva 裡的做法

用 Canva 的角色圖片加上「文字轉語音」，嘴巴靠動畫開合。老師已經有一頁示範：https://claude.ai/artifact/2Dki9d8gQMqUhQv5ek6wdz （11/12 做的，主播叫「小橋」）。

1. 準備三張角色圖：**閉嘴**、**張嘴**（只換嘴巴，其他不動）、**眨眼**。
2. 閉嘴和張嘴兩張每 0.2 秒輪流換，存成透明背景 GIF，就是「說話 GIF」。
3. Canva 時間軸：
   - 最底層放「閉嘴」主播，時間拉滿整段。
   - 上面疊「說話 GIF」，位置對齊，只留在有聲音的地方。
   - 一句話對一段 GIF，停頓時 GIF 消失，主播自然閉嘴。
4. 聲音用 Canva 的文字轉語音，或學生自己錄。

### 1.3 紙娃娃系統要解決的問題

學生在 Canva 用形狀拼角色很花時間，成品也常常長得很像。紙娃娃系統讓每個學生在一節課內用點選組出一個不一樣的主播，並直接下載上面那三張圖和說話 GIF，帶去 Canva 用。

### 1.4 老師的要求（原話整理）

- 適合**國小五年級**，能產生像示範主播那樣的**卡通角色**。
- 要有**半身**和**全身**。
- 樣式要**多樣化**，滿足學生的各種喜好，學生可以自由組合。
- 選擇的豐富程度要像 https://morrisrrrrrrr-svg.github.io/avatar-maker.html （楓之谷紙娃娃），**但畫風要多樣，不是只有像素風**。
- 需要的圖可以請 **Codex** 去生。

### 1.5 教室現場的限制

| 項目 | 狀況 |
| --- | --- |
| 使用者 | 五年級學生，電腦教室用 Chrome；不登入、不安裝 |
| 螢幕 | 以 **1366×768** 為準，預覽和選項要一頁放得下、不捲動；平板也要能操作 |
| 時間 | 目標：學生 **15 分鐘內**完成角色並下載 |
| 隱私 | 沒有帳號、沒有伺服器、不收任何學生資料；不能上傳照片 |
| 存檔 | 存在瀏覽器裡；電腦教室**有沒有還原卡還沒確認**，所以一定要有「角色代碼」可以帶走 |
| 內容 | 原創部件；不做現有動漫、遊戲、偶像的造型，不放商標、真實隊徽；服裝不暴露、沒有真實武器、沒有血腥恐怖；膚色、髮型、服裝不分性別 |
| 角色名字 | 10 個字以內，只用在下載的檔名 |

## 4. 程式架構（v0.2）

整個工具是一個 HTML 檔，沒有外部函式庫，也沒有建置步驟。

### 4.1 畫面

- 左邊：預覽，以及隨機、說話預覽、翻轉、背景、復原、重設這些按鈕，下面是目前搭配。
- 右上：分類分頁、選項縮圖、色票。
- 右下：命名和角色代碼，以及下載區。
- 標題列有「畫風」下拉選單 `#styleSel`。

### 4.2 部件與疊圖

- 畫布 1000×1000，半身，身體下緣貼齊 y=1000。
- 每個部件是一段 **SVG 片段**，只能用 `g path circle ellipse rect line polyline polygon`。
- 顏色用代號寫，畫的時候換成學生選的顏色：

| 代號 | 意思 |
| --- | --- |
| `{skin}` `{skin2}` | 膚色、暗一階的膚色（脖子、耳朵、鼻子） |
| `{hair}` `{hair2}` | 髮色、暗一階的髮色（眉毛） |
| `{eye}` | 眼睛顏色 |
| `{c1}` `{c1d}` | 衣服主色、暗一階的主色 |
| `{c2}` | 副色 |
| `{hat}` | 帽子顏色 |

- 11 個分類，`ORDER = face hair brow eyes mouth nose deco glasses hat top hand`。
- 疊圖順序，在 `inner()` 裡，從底到頂：

  後髮 → 上衣 → 脖子 → 耳朵 → 臉型 → 臉部裝飾 → 嘴巴（閉／張） → 鼻子 → 眼睛（開／眨） → 眉毛 → 前髮 → 眼鏡 → 帽子頭飾 → 手持物

- 特殊欄位：眼睛有 `open` 和 `blink`，嘴巴有 `closed` 和 `open`，髮型有 `front`，`back` 可省略。其他分類都用 `svg`。
- 色票：`SKIN` 6 色、`HAIRC` 12 色、`EYEC` 8 色、`CLOTH` 12 色。

### 4.3 風格包

- 扁平風（id `flat`）直接寫在 HTML 裡，是預設，也是載入失敗時的備援。
- 其他畫風在 `packs/index.json` 列出來，選了才 fetch `packs/<id>/pack.json`。
- 重點函式：
  - `loadStyle(id)`：載入並驗證 11 類都在。
  - `usePack(p)`：換掉 `PACK`、`VIEW`、`BASE`、`PARTDEF`、`DEFAULT`。
  - `setStyle(id, keepParts)`。
- pack.json 的結構看 `packs/README.md`。`view` 是各分類選項縮圖的放大範圍（viewBox）。

### 4.4 角色資料、存檔、代碼

- `state` 欄位：`v, style, name, skin, hairC, eyeC, c1, c2, hatC, flip, bg`，再加 11 類各自選的部件 id。
- 自動存檔：localStorage key `dq-avatar-v1`。
- 角色代碼：`'DQ1-' + base64(UTF-8 JSON)`。還原時先載入代碼裡的畫風，再套用部件。
- `sanitize()` 會擋掉不合法的值。
- 復原最多 40 步。

### 4.5 下載（全部在瀏覽器裡產生）

| 按鈕 | 內容 | 檔名 |
| --- | --- | --- |
| 下載 PNG | 閉嘴，1000×1000 透明 PNG | `名字.png` |
| 下載主播包（zip） | 閉嘴、張嘴、眨眼三張 PNG，加上說話 GIF | `名字_閉嘴.png` 等 |
| 只下載說話 GIF | 500×500 透明 GIF，每格 0.2 秒，10 格裡有 1 格眨眼 | `名字_說話.gif` |

- GIF 編碼器（LZW）和 zip（不壓縮、UTF-8 檔名、CRC32）都是自己寫的，在 `makeGif()` 和 `makeZip()`。
- 測試用介面：`window.__avatar`，提供 `state`、`svg`、`enc`、`dec`、`PACK`、`VIEW`、`BASE`、`PARTDEF`、`setStyle`、`buildGif`。

### 4.6 工具程式

- `python avatar-maker/tools/check_pack.py avatar-maker/packs/<id>/pack.json`
  - 檢查：必填欄位、11 類、編號重複、眼睛和嘴巴的兩種狀態、預設值存在、只用已知的顏色代號、只用允許的標籤（禁止 script、image、text、use、style、href、url()、on*）、XML 寫法正確、款數下限。
  - 通過後輸出 `overview.svg`：每個部件套在預設角色上，眼睛和嘴巴附眨眼、張嘴的小圖。
- `tools/make_chibi.py <flat_pack.json> <out>`：示範怎麼由扁平風轉出另一種畫風。頭部放大 1.3 倍，身體縮成 0.74 倍，加描邊，眼睛和嘴巴重畫。

### 5.2 實作和規格書不一樣的地方（v0.2）

- 規格書寫「可換色區域標 class、一個部件一個檔案、manifest.json」。實際做法改成「顏色代號 `{c1}`、整包放在一個 pack.json」，因為檢查和載入都比較簡單。要繼續用 pack.json，或改回規格書的寫法，由你判斷，但要同步更新 `packs/README.md` 和 `check_pack.py`。
- 目前只有半身 1000×1000。全身要擴充畫布、素體和疊圖順序，pack 格式也要加版本號，例如 `"format": 2`，舊包要能相容。
- 表情目前做在「嘴巴」和「眼睛」裡，還沒有獨立的表情選單。
